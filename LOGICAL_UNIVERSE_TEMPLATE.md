# Logical Universe Template

> **Purpose:** copy this file when defining a new QCDS Logical Universe. The template itself contains no active universe, no oracle and no truth claim. It exists to keep new logical spaces explicit, isolated, falsifiable and compatible with the QCDS/Syntract architecture.

A Logical Universe is **not** required to be a hierarchy, ontology or knowledge graph. Its represented logic may remain open-ended and non-hierarchical. QCDS, its oracle regime and the **Syntractfilter** determine which dimensions become relevant for a particular inference.

For an `observed` universe, rules are hypotheses about reality and require evidence/challenge before promotion. For a `declared` universe, the declared authority defines the constitutive rules of that universe. `hypothetical` and `simulation` universes must remain explicitly scoped and must not silently leak conclusions into `reality`.
