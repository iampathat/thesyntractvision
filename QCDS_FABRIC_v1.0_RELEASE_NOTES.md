QCDS Fabric v1.0 freezes the scalable inference-fabric architecture surrounding the four canonical QCDS phases and places that architecture directly inside The Syntract Vision repository.

## Locked in v1.0

- same active oracle regime before each comparable channel;
- parallel QCDS channel banks;
- Rotational Dimension Nulling;
- explicit `∅ != 0 != ?` semantics;
- positional rotation as a distinct position-bias diagnostic;
- oracle exposure rotation as a distinct oracle-sensitivity diagnostic;
- physical quantum amplitude/phase evolution as a separate substrate mechanism;
- stabilization before higher-order recursive funneling;
- parallel breadth inside layers and serial recursive depth between layers;
- configurable widths rather than a fixed 8-bit architecture;
- separation of independent logical dimensions from derived diagnostic views;
- substrate-independent semantics;
- conformance, ablation, and falsification requirements.
