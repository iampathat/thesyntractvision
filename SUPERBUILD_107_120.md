# SUPERBUILD 107–120 — The Living Superintelligence

Status: implementation plan + release guardrails

This superbuild changes the **public manifestation** of The Syntract Vision. It does not replace, fork or reinterpret QCDS.

## Architectural invariants

These are release blockers for every build in 107–120:

1. There is **one QCDS / Syntract intelligence architecture**.
2. `SyntractSystem` remains the public composition boundary around the existing QCDS core, Fabric, mission/runtime, central execution, swarm, evidence and Logical Robot loops.
3. Logical, simulated, browser, legal, scientific, sensor and physical robots are **bodies / capability surfaces** around that same intelligence. They must not gain their own inference engine.
4. The canonical four phases remain unchanged: Condition Formation → Conditional Evolution → Recursive Inference → Truth-Alignment / Syntract Binding.
5. `0`, `1`, `?` and logical `∅` keep their canonical distinct meanings.
6. TruthDistribution remains distribution-first. A tie or multimodal result must not be silently collapsed into false certainty.
7. Bias damping remains a measurable architectural objective, not a claim that all bias is eliminated.
8. Parallel Syntract composition keeps complete source TruthDistributions and uses existing QCDS re-entry. No voting, no hidden hard collapse, no new fusion engine.
9. Human text, retrieved material and sensor observations are input/evidence, not automatic truth.
10. External actions remain governed by the body/executor authorization and safety boundary.
11. Browser teaching visualizations may explain combinatorics and masks, but must be labelled as teaching views and must never pretend to be a second QCDS implementation.
12. Present software demonstrations must be separated from architectural targets and future native-QPU / superintelligence claims.

## Release story

The public site should make one continuous idea visible:

```text
REALITY / QUESTION
      ↓
REPRESENTED LOGICAL SPACE
      ↓
ORACLES / EVIDENCE / CONSTRAINTS
      ↓
QCDS
  represent → constrain → infer → bind
      ↓
STABILIZED TRUTH DISTRIBUTION / SYNTRACT
      ↓
WHAT HOLDS? · WHAT IS STILL UNCERTAIN?
      ↓
WHAT SHOULD BE OBSERVED / TESTED / DONE NEXT?
      ↓
LOGICAL OR PHYSICAL BODY
      ↓
NEW EVIDENCE / CHANGED REALITY
      ↺
```

The superintelligence direction is the increasingly capable, recursive and continuous operation of this **same loop** across larger logical spaces, better oracle regimes, multiple diagnostic views, higher-order Syntracts, many bodies and greater execution capacity.

## Build map

- **107 — Freeze & Map:** lock the invariants and preserve the existing public surface underneath the new manifestation.
- **108 — One Story:** add one public superintelligence narrative above the existing capability surfaces.
- **109 — 8 Switches:** teach `2^8 = 256` with eight binary switches and exact states.
- **110 — Oracle Overlap:** teach masks such as `1011011?` and intersections without additive-count confusion.
- **111 — Bias Lens:** explain null / positional / oracle-view diagnostics without changing inference semantics.
- **112 — What Holds:** make uncertainty, multimodality and stabilized distribution visible.
- **113 — What Next:** connect uncertainty to evidence / experiment planning and action selection.
- **114 — The Loop:** show continuous re-entry and measured timing only where an actual measured execution is available.
- **115 — Intelligence Growth:** expose oracle-gap → hypothesis → challenge → quarantine/promote → re-infer.
- **116 — Many Bodies:** DNA, cancer research, tokamak, legal, web and robotics as bodies around one QCDS core.
- **117 — Syntract Recursion:** complete Syntracts re-enter as higher-order QCDS structure without fusion/voting.
- **118 — Scale Out:** parallel / sequential / hybrid / swarm as capacity around the same intelligence.
- **119 — Now / Next / Horizon:** explicit claim boundary.
- **120 — Conference Release:** integrate, test, simplify, optimize and publish the new public manifestation.

## Non-goal

This superbuild does **not** create a new `SuperintelligenceEngine`, `FusionEngine`, domain-specific QCDS clone, browser inference clone, or management intelligence above QCDS.
