What this engine does — and does not do

The Python QCDS Fabric from this repository runs independently on each explicit claim. It produces stabilized truth distributions, entropy and possible contradiction markers. The evidence synthesis below uses declared, human-auditable rules to identify questions and gaps. It is not a trained plagiarism detector, a judgment of intent, a legal opinion or evidence of quantum advantage. An unknown input means there is no supplied oracle assertion.
