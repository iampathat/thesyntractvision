03 · READ THE RESULT CORRECTLY

Discovery is not verification.

Glasswing deliberately separates candidate generation from truth. A route can be plausible, conditional, supported, refuted or conflicting. QCDS does not win by producing the longest list. It earns confidence only when surviving claims remain coherent under changed perspectives, changed dimensions, control challenge, counter-tests and evidence.
