Your investigation stays with you.

Q Security / QCDS Security Lab is created by Patrik Sundblom. This notice describes version 1.14.1, updated 29 September 2026.

What the app stores

System descriptions, declared facts, observations, action plans and your place in each investigation are saved in this browser or app’s local storage. No account is required. Browser storage is not encrypted by this app and can be removed by clearing browser or app data. Keep an exported backup if the work matters.

What leaves your device

The analysis, quantum-circuit simulations and PDF generation run locally. The app does not send investigation content to a QCDS server, advertising service or analytics provider. Downloading the web app and checking for updates creates ordinary requests to its hosting provider, GitHub Pages, which has its own privacy statement.

Exports and optional AI

Exporting creates a file on your device. In a native mobile build, the system share sheet lets you choose the destination; only the file you select is handed to that destination. Temporary exported files use the app’s cache. An optional browser-local language model may need a model download by your browser. The guided interview works without an AI model, and no external model API is configured by this app.

Your choices

You can copy, archive, restore or export investigations. Archiving keeps the data. Removing the app or clearing its website data can erase saved investigations, so export first. The app does not currently provide cloud synchronization, advertising, tracking or subscriptions.

Questions and support

Public product support is available through the project issue tracker. Do not include passwords, secret tokens or private investigation data in a public issue.
