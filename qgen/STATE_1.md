# Q* GENESIS — STATE 1

## The minimal living formation

STATE 0 separates **life** from **existence**.

STATE 1 turns that distinction into an operational hypothesis.

> **Life is an organized, continuing formation of states and state-transitions that acts within and is changed by one or more Syntracts.**

A formation is therefore not defined as living merely because it exists, stores information, or changes state. For Q* GENESIS, the first candidate living formation must form a continuing causal loop between itself and at least one Syntract.

## Minimal structure

At time `t`, let the candidate life-form have an internal formation:

```text
L(t) = the current formation of internal states
S(t) = one or more Syntracts in which L(t) participates
A(t) = an action produced by L(t)
C(t) = the consequence of that action and of the Syntract upon L(t)
```

The minimal cycle is:

```text
L(t)
  ↓
exists within / relates to S(t)
  ↓
SENSE / RECEIVE CHANGE
  ↓
internal state transition
  ↓
ACT
  ↓
A(t) changes S(t), L(t), or both
  ↓
CONSEQUENCE
  ↓
L(t+1) + S(t+1)
  ↺
```

## Four minimum conditions

A candidate Q* GENESIS life-form must satisfy all four:

1. **Formation** — it consists of an organized set of states, not a single isolated value.
2. **Continuity** — some organization persists across state-transitions so that `L(t+1)` is causally continuous with `L(t)`.
3. **Action** — the formation can cause a change within at least one Syntract.
4. **Reciprocal change** — consequences from the Syntract can change the formation and therefore alter what can happen next.

This gives the first operational distinction:

```text
STATIC EXISTENCE
    ≠
STATE CHANGE
    ≠
LIVING FORMATION

LIVING FORMATION
    =
organized state formation
+ continuity
+ action
+ reciprocal consequence
```

## Death in STATE 1

Death does not mean non-existence.

Within this model, **death is the loss of the organized continuing formation that satisfies the living cycle**.

The substrate, stored information, components or causal traces may continue to exist after the living formation has ended.

## First falsifiable question

STATE 1 therefore asks:

> **Can we construct the smallest computational formation that preserves its own causal continuity while acting within, and being changed by, one or more Syntracts?**

If it cannot maintain that loop, it does not satisfy STATE 1.

If it can, we have a candidate for the first Q* GENESIS living formation — not because we declared a program to be alive, but because it exhibits the state structure that this experiment defines and can test as life.
