# Q* GENESIS — STATE 2

## Goal as the preferred next state

STATE 1 defines a minimal living formation as an organized, continuing formation of states and state-transitions that acts within, and is changed by, one or more Syntracts.

STATE 2 introduces **direction**.

A living formation is not only moving from one state to another. At any moment, there may be several possible next states. A **goal** is the state — or region of states — toward which the living formation directs its next transition.

> **Goal = a preferred next state.**

This separates two things:

- **Next State** — the state that actually occurs next.
- **Goal State** — the state the living formation is directing itself toward.

They may be the same, but they do not have to be.

## World, Syntract and Goal

For Q* GENESIS:

```text
W(t) = the World at time t
S(t) = one or more Syntracts in which the living formation is acting
L(t) = the current living formation
P(t) = the set of possible next states
G(t) = the preferred next state / Goal
A(t) = the action directed toward G(t)
L(t+1) = the actual next living state
```

The **World** is the larger field of states, conditions and relations around the living formation.

A **Syntract** is the active relational formation through which the living formation encounters and acts within that World.

The **Goal** is not necessarily a distant objective. At the most primitive level, it is simply a preferred next state.

## The directed living cycle

```text
WORLD
  ↓
CURRENT STATE L(t)
  ↓
ONE OR MORE SYNTRACTS S(t)
  ↓
POSSIBLE NEXT STATES P(t)
  ↓
GOAL G(t)
= preferred next state
  ↓
ACTION A(t)
  ↓
CONSEQUENCE
  ↓
ACTUAL NEXT STATE L(t+1)
  ↓
new possibilities
  ↓
new preferred next state
  ↺
```

A living formation therefore does not require one permanent objective.

A goal can be local and temporary. Reaching, missing or partially reaching one goal changes the current state, which changes the next possibility space and can produce the next goal.

```text
STATE₀
  ↓
GOAL₁
  ↓
ACTION₁
  ↓
STATE₁
  ↓
GOAL₂
  ↓
ACTION₂
  ↓
STATE₂
  ↺
```

## Goal is not command

An externally assigned command can become a goal, but a goal does not need to originate externally.

A living formation may produce a preferred next state from its own current formation and its relation to a Syntract.

For example:

```text
current formation changes
        ↓
possible next states change
        ↓
one next state becomes preferred
        ↓
action is directed toward it
        ↓
consequence changes the formation
        ↺
```

This gives Q* GENESIS a minimal concept of direction without requiring language, reward scores, human-like motivation or a pretrained model.

## STATE 2 hypothesis

The first synthetic life-form should therefore be able to represent more than one possible next state, establish a preferred next state, act toward it, receive the consequence, and continue from the state that actually results.

**Life persists by continuously forming and pursuing preferred next states within one or more Syntracts.**
